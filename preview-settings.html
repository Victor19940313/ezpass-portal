筆記「AI / 圖床 設定」簡化 — 兩個方案預覽

現況:一打開就是一整頁鑰匙、token、repo、模型、安全提醒,新手會被嚇到。下面兩個方案都把「第一次只要做一件事」放最前面,其他收進去;入門指引直接放在設定裡,不用靠使用者自己去找。畫面是靜態示意,按鈕沒有功能。

方案 A|一眼一件事
打開只看到「貼一把 AI 鑰匙」。申請步驟、多把鑰匙、模型、貼圖、安全說明全部收成一行,想看再點開。最短、最不嚇人。

⚙️ 筆記設定

📖 第一次用? 看 3 分鐘入門指引,照著走就好

設定綁在你的帳號上,換手機、換科目都不用重設。

🤖 AI 鑰匙(做筆記要用)
還沒有鑰匙?免費、不用綁卡、3 步驟 ▸
  1. 點 Google AI Studio,用任何 Google 帳號登入
  2. 按藍色「+ Create API key」→「Create API key in new project」
  3. 複製那串 AIzaSy 開頭的字,貼回上面
進階:多貼幾把鑰匙、換模型 ▸

(這裡才放「+ 新增一把 key」和「使用模型」下拉,預設不用動)

📷 筆記貼圖(選用,可以先跳過)

想在筆記裡貼截圖才需要。要一個 GitHub 帳號 + 一把 token,照步驟 5 分鐘。

申請 token 詳細步驟 ▸
🔒 鑰匙只存在你自己的帳號裡,不要給別人 ▸

就像家裡的鑰匙,給別人就會被拿去用你的額度。截圖前先確認「顯示」沒打勾。不小心外洩:回 Google AI Studio / GitHub 把舊的刪掉、重新申請一把貼回來就失效了。連 ezpass 的管理者都看不到。

方案 B|照 3 步走(入門指引直接長在裡面)
把入門指引的三步驟直接排成設定畫面:做到哪一步會打勾,沒做的一眼看得出。給「不會乖乖看指引」的人:不看也會照著走。

⚙️ 筆記設定

① 拿鑰匙 ✓② 貼進來測試③ 回去做題
1

拿一把免費 AI 鑰匙(不用綁卡)

  1. 點 Google AI Studio,用任何 Google 帳號登入
  2. 按藍色「+ Create API key」→「Create API key in new project」
  3. 複製那串 AIzaSy 開頭的字
2

貼進來,按一下測試

🔒 這把鑰匙只存在你的帳號裡,不要給別人;截圖前確認沒打勾「顯示」。

3

回到考題,答完按「📒 加入筆記」

AI 會把那題的重點整理進你的筆記本;之後做題按「📖 偷看筆記」隨時翻。

進階(筆記貼圖、多把鑰匙、換模型)▸

貼圖要 GitHub token + repo(有申請步驟);多貼幾把鑰匙撞額度會自動換;模型預設就好。
